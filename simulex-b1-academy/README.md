# SimuLex Academy B1 — English Interface / German Questions

A single-file, offline-capable study SPA for German B1 model-test practice.

## Included

- English navigation, headings, explanations, and analytics.
- German question and source text retained from the structured dataset.
- All **1,323** question/task records and all **23** model records retained.
- Progressive path, foundations, guided practice, exam mode, mistake lab, adaptive analytics, writing drafts, and German pronunciation/shadowing.
- Transparent answer verification: uncertain keys remain visible and are not guessed.
- One-click CodeSandbox deployment using LZ-String Base64 compression and a static sandbox configuration.
- Local-only progress storage and JSON export.

## Run

Open `index.html` in a modern browser. No build step is required.

## GitHub Pages

When GitHub Pages is configured to publish this repository branch, the application can be opened from the folder path containing `index.html`.
